Ode starts with restraint. The palette comes from paper, dust, and sun rather than glossy SaaS defaults. The layout is narrow, deliberate, and slightly severe so the writing stays in control.

This first pass is intentionally static. It is enough to establish the visual language, prove the deployment path on Railway, and leave room for the content system to evolve later.

## Design rules

- Navigation uses Iosevka Aile so it reads like a system label strip.
- Body copy and article blocks use Schibsted Grotesk for a cleaner editorial rhythm.
- Cards and content chips lean on `#D5C4A1` to echo the reference site's low-contrast blocks.

:::note
The goal is not a literal clone. It is a close study of tone: warm, technical, compact, and personal.
:::

快速心智模型

Quarkdown 是 Markdown 的增强版。它保留了 Markdown 的基本写法，同时引入了“函数调用”来控制排版、文档信息、布局、计算和引用。

你可以把一份 Quarkdown 文档拆成三层：

  1. Markdown 层：标题、段落、列表、引用、链接、代码块。
  2. 文档层：标题、作者、语言、页面类型、页边距、目录、页码。
  3. 函数层：变量、条件、循环、自定义组件、图表、布局容器。

如图 所示，最常见的工作流就是：写 main.qd，编译，预览或导出。

字体设置：中文、俄语和混排

字体排错清单

如果你导出的 PDF 里中文或俄语显示不对，按这个顺序查：

  1. 字体名是否写对。字体家族名不一定等于文件名。
  2. 当前系统是否真的安装了这个字体。
  3. 字体是否覆盖目标字符，比如俄文字体要支持 Cyrillic。
  4. font-family fallback 里有没有可用兜底字体。
  5. 如果用本地字体文件，路径是否相对 main.qd 正确。
  6. 如果发布 HTML，字体文件是否会一起部署。

Quarkdown 里的字体边界

结语

Quarkdown 最好的学习方式不是先背完所有函数，而是先写一篇真实文档：封面、目录、图片、表格、公式、页码，这些一旦跑通，你就已经能完成大多数 PDF 和技术长文。

  2. 用 quarkdown c main.qd -p -w 边改边看。
  3. 改出一份你自己的讲义、论文笔记或项目说明书。
